## 📝 我的个人博客 & 论坛

一个使用 Python Flask 构建的中文个人博客和论坛系统。

### 功能特性

- 📰 **博客首页** — 展示所有文章，支持摘要预览
- ✏️ **发表文章** — 写并发布个人博客文章
- 💬 **论坛广场** — 浏览所有论坛帖子
- 🖊️ **发帖 & 回复** — 发布新帖子并参与讨论

### 快速开始

```bash
# 1. 安装依赖
pip install -r requirements.txt

# 2. 启动应用
python app.py

# 3. 打开浏览器访问
# http://127.0.0.1:5000
```

### 技术栈

- **后端**: Python 3 + Flask
- **数据库**: SQLite（内置，无需额外安装）
- **前端**: 原生 HTML/CSS，响应式布局，支持中文字体
